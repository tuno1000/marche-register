### 変更：税率に 1% と「税込み」を追加（2026-11-08、`main`）
- 商品の税率を「1% / 8% / 10% / 税込み」から選べるようにした（`e81890e`）
- 「税込み」は税率を決めずに扱い、内消費税を計算しない。データでは税率 `0` として持つ（`TAX_INCLUDED`、表示は `taxRateLabel()`）

  - バックアップの形の検査も 0 と 1 を受け付けるようにした
- 1% はほかの税率と同じく内消費税を計算する
- 決めたこと：「税込み」の意味は、ユーザーに確かめて「内税を計算しない」にした（ほかの案：税率別に金額だけ出す、価格の入力を税抜き／税込みで切り替える）
