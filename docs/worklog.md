### 主な決定事項
| 分類 | 決定内容 |

| DD-2 レシート | 店名・登録番号などは会計したときの内容を取引に保存し、あとで設定を変えても過去のレシートは変わらない |
| DD-3 イベント | 会計したことのないイベントだけ削除できる |
| CSV | 15 列、明細単位、取消も「状態」列付きで出力する。お預かり・お釣りは出さない |
