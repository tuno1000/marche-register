### 実装：M1 データと計算（ブランチ `feature/m1-data`、M0 のブランチから分岐）
- 作ったもの
  - `src/domain/`：型（types.ts）、エラー（errors.ts）、整数の割り算と按分（integer.ts）、値引き（discount.ts）、1 取引の計算（checkout.ts）、取引番号（receiptNo.ts）、集計（summary.ts）
  - `src/db/`：Dexie の定義（schema.ts）、設定などの値（kv.ts、defaults.ts）、入力のチェック（validate.ts）
  - `src/db/repositories/`：カテゴリ、商品（画像を含む）、イベントと持ち込み在庫、取引（会計の確定・取消）、カート
- 決めたこと（ドキュメントに細かく書いていなかった部分）
  - 型定義は `domain/types.ts` に置いた（04 を v1.1 に更新）
  - 値引きの定型ボタンの初期値の ID は固定（`preset-50yen` など）。保存前に何度読んでも同じ ID になるようにするため
  - 会計の確定では、削除した商品があればエラーにする。「販売休止」の商品はカートに入っていれば売れる

- テスト：1,064 件すべて合格
